# Online Shopping Cart (Java)

## Description
This is a Java Swing based Online Shopping Cart application.
Users can select items, add quantity, view cart details,
calculate total price, and clear the cart.

## Technologies Used
- Java
- Java Swing
- ArrayList
- HashMap

## Features
- Add items to cart
- View cart
- Calculate total price
- Clear cart

## How to Run
1. Install JDK
2. Open the project in any Java IDE
3. Run `ShoppingCart.java`
